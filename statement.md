# Project Statement

## Title
Hospital Management System

## Problem
Manual management of patients, doctors, appointments, medical records, and bills can lead to duplicate records, appointment conflicts, and difficulty retrieving information.

## Objective
Develop a command-line Java application that organizes basic hospital operations using object-oriented programming and persistent local file storage.

## Functional Modules
1. Patient Management
2. Doctor Management
3. Appointment Management
4. Medical Record Management
5. Billing Management
6. Search and Reporting

## Input
The user enters patient, doctor, appointment, medical record, and billing details through the command line.

## Processing
The application validates input, checks IDs, prevents duplicate patient/doctor IDs, detects doctor appointment conflicts, calculates bills, and stores data using Java serialization.

## Output
The system displays patient lists, doctor lists, appointments, medical records, bills, payment status, and patient search results.

## Constraints
- Core Java only
- No database
- No external libraries
- Command-line execution

## Expected Outcome
A reliable console-based system demonstrating practical use of Java OOP, collections, validation, exception handling, searching, sorting, and file persistence.
